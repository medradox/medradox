# Priorização de processos com Python e SQL

**Análise de dados · Automação · Impacto de negócio**

Estudo de caso de uma aplicação profissional. Esta página documenta o contexto e o resultado; scripts e dados operacionais não estão publicados neste repositório.

## Contexto

Uma rotina de priorização de pátio precisava apoiar decisões recorrentes e reduzir o tempo de espera de descarga.

## Solução

Automatizei a priorização com **Python e SQL**, conectando tratamento de dados e regras de negócio à organização da fila operacional.

## Resultado

| Indicador | Antes | Depois |
| :--- | :--- | :--- |
| Tempo de espera | 15 dias | 2 dias |

A redução foi de aproximadamente **87%**, calculada como `(15 − 2) / 15`.

## Competências aplicadas

Análise de processos, tratamento de dados, tradução de critérios de negócio em regras de priorização e automação de rotinas.

`Python` `SQL` `Automação` `Análise de dados`
